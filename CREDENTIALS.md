## 🧪 Interactive Testing Workflows

You can open two different browser profiles or an Incognito window to test end-to-end multi-role workflows:

### Scenario 1: Breakdown Complaint to Repair Resolution
1. **Login as Operator** (`priyanshuc675@gmail.com`):
   - Navigate to **Complaints** or **Equipment**.
   - Select the assigned *Cincinnati 175-Ton Hydraulic Press Brake*.
   - Submit a breakdown report: "Hydraulic proportional valve drifting on ram down-stroke".
2. **Login as Technician** (`tech.production@gearguard.com`):
   - Navigate to **Kanban Board** or **Work Orders**.
   - Drag the newly created ticket from **New Request** to **In Progress**.
   - Open ticket details, log repair notes, and set status to **Repaired**.
3. **Verify Synchronized Machine State**:
   - Return to the equipment view—notice the machine's `last_maintenance_date` automatically updated and MTTR records synchronized.

### Scenario 2: New Asset Procurement Request & Manager Approval
1. **Login as Operator** (`jane@gearguard.com`):
   - Navigate to **Asset Requests**.
   - Submit a request for a new high-speed milling spindle.
2. **Login as Manager** (`manager.machining@gearguard.com`):
   - Navigate to **Asset Requests / Approvals**.
   - Review the requisition, inspect budget allocation, and click **Approve**.

### Scenario 3: Compliance Audit & Log Review
1. **Login as Auditor** (`auditor@gearguard.com`):
   - Navigate to **Audit Logs**.
   - Inspect immutable timeline entries for technician actions, state changes, asset handovers, and system modifications.
   - Export or filter logs by date and department.
